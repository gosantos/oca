On tools that disappear

Why the best interfaces are the ones we forget are there.

A good tool vanishes the moment you start using it. The hammer stops being a hammer and becomes an extension of your arm; the text editor becomes just the text.

The cost of attention

Every element on a screen asks for a little attention. One more button, one more color, an animation nobody asked for. Alone they seem harmless. Together they turn work into noise.

Perfection is achieved, not when there is nothing more to add, but when there is nothing left to take away.

Antoine de Saint-Exupéry wrote that about airplanes, but it holds for anything someone has to use every day.

Three signs of excess

  1. You have to explain where a feature lives.
  2. The screen has more than one focal point.
  3. The user asks "what does this do?" before "how do I do this?".

In practice

Start with text. Add structure only when the text asks for it. Use one color for one thing. If everything is highlighted, nothing is.
