Sobre ferramentas que desaparecem

Por que as melhores interfaces são as que a gente esquece que existem.

Uma boa ferramenta some no momento em que você começa a usá-la. O martelo deixa de ser martelo e vira extensão do braço; o editor de texto vira só o texto.

O custo da atenção

Cada elemento numa tela pede um pouco de atenção. Um botão a mais, uma cor a mais, uma animação que ninguém pediu. Isoladamente parecem inofensivos. Somados, transformam o trabalho em ruído.

Perfeição é atingida não quando não há mais nada a adicionar, mas quando não há mais nada a retirar.

Antoine de Saint-Exupéry escreveu isso sobre aviões, mas vale para qualquer coisa que alguém precise usar todo dia.

Três sinais de excesso

  1. Você precisa explicar onde fica uma função.
  2. A tela tem mais de um ponto focal.
  3. O usuário pergunta "o que isso faz?" antes de "como faço isso?".

Na prática

Comece com texto. Adicione estrutura só quando o texto pedir. Use uma cor para uma coisa. Se tudo é destaque, nada é.
